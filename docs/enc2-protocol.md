# 컴시간 enc2 대응 및 검증

확인일: 2026-11-06. 기준 main: `ee39365b6875a8544628c6a3043527de270be2ed`.

## 변경 사항

- 공식 학생 페이지를 문자열로 복원한 뒤 검색 경로, 요청 코드, 자료 필드 번호뿐 아니라 응답 키와 학교 코드 열 계산 규칙도 읽는다. 원격 JavaScript는 실행하지 않는다.
- 암호화 프로토콜을 사용하는 페이지에서는 학교 검색어 뒤와 시간표 Base64 인코딩 전 토큰 끝에 `_enc2`를 붙인다.
- `enc2:IV:암호문:인증값`의 Base64 표현과 길이를 확인하고, `SHA-256(응답 키)`를 키로 쓰는 HMAC-SHA256을 검증한 뒤 AES-CBC/PKCS7 응답을 읽는다. 공식 페이지의 `enc1` Hex 표현도 처리한다.
- 학교 코드 위치는 페이지에서 읽은 `floor(row[0] / divisor) + offset`으로 계산한다. 고정 `row[3]`의 미끼 값을 학교 코드로 쓰지 않는다.
- 암호화 응답이 필요한데 평문 `{}`가 오면 형식 오류로 처리한다. 인증된 응답을 복호화한 결과가 비어 있는 경우에만 기존 미게시 판정을 적용한다.
- 형식·인증 오류 시 캐시된 서비스 코드를 폐기하고 페이지를 다시 읽어 한 번 재시도한다. 페이지의 경로·키·필드 번호가 바뀐 경우를 처리하기 위한 것이며 무한 재시도하지 않는다.
- 빌드 버전: `1.0.2` / versionCode `12`. 기존 `-dontobfuscate`, 코드 최적화 및 리소스 축소 설정을 유지한다.

## 자동 및 실서버 검증

- JVM 테스트 39개 통과: 기존 모델·나이스·파서 테스트에 암호화 요청, 독립적으로 생성한 고정 암호문, 가변 학교 코드 열, 변조·잘못된 키·잘못된 인코딩·평문 거부 검증을 추가했다.
- 실제 Kotlin 클라이언트로 중일고등학교 학교 검색 및 1학년 1반 조회 성공: 2026-11-02 주간 수업 29개, 2026-11-09 주간 수업 34개.
- Release APK 빌드와 Release Lint 통과.
- 기존 배포 인증서 일치, 비디버그 APK, 16KB 정렬, 최종 DEX의 내장 나이스 키 및 개인 빌드 입력 파일 제외 확인. 키 값과 서명 자격 증명은 로그에 남기지 않았다.
- 응답 키·경로·필드 번호·학교 코드 열 계산 상수는 운영 서버의 실제 값을 소스에 고정하지 않는다. 테스트 암호문은 합성 자료와 테스트 전용 키로 생성했다.

## SM-A336N 실기기 검증

배포 서명 APK로 `1.0.1/code 11`에서 `1.0.2/code 12`로 업데이트했다. 앱 데이터 삭제나 재설치는 하지 않았다.

1. 기존 학교·2학년 1반 설정으로 콜드 스타트와 최신 시간표 자동 조회 성공.
2. 설정의 학교 변경 화면에서 한글 학교 검색 성공.
3. 검색 결과 선택 후 서버 시간표를 읽어 학년·반 선택 미리보기 성공. 선택을 저장하지 않고 기존 학급으로 복귀.
4. 기존 학급의 강제 새로고침, 이번 주(11월 2일) 및 다음 주(11월 9일) 시간표 표시 성공.
5. 원래 학급과 오늘 화면으로 복원. 동일 프로세스 유지 및 검증 구간 내 신규 예외 충돌 없음.

APK·SHA256SUMS·서명 검증 결과와 원본 실기기 캡처는 로컬의 무시된 `work/` 디렉터리에 보존하며 저장소에는 포함하지 않는다. 검증용 단말 임시 파일은 정리했다.
