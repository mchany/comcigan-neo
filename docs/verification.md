## 시간표·급식 홈 위젯 — 2026-10-28 KST

- 기준: 앞선 초기 설정·알림 기능을 포함하는 최신 워크스페이스. 버전 `0.2.1-beta` / versionCode `4`를 유지하는 개발용 디버그 APK다.
- 오늘 시간표와 급식 각각 2×2·4×2 기본 크기, 총 네 가지 위젯을 등록했다. 크기·방향에 따라 배치를 바꾸며, Android 12 이상은 반응형 RemoteViews와 인메모리 컬렉션, Android 8~11은 방향별 레이아웃과 RemoteViewsService를 사용한다. 신규 라이브러리는 추가하지 않았다.
- 예시의 둥근 카드·파스텔 색상·물결 장식을 네이티브 레이아웃과 Canvas 배경으로 구현했다. 넓은 시간표는 왼쪽 요약·오른쪽 교시 목록으로 나눠 호스트 검증 크기 360×210dp에서 7교시 전부가 보이는 것을 확인했다. 작은 위젯은 다음 시작 수업과 이후 수업을 요약한다. 종료 시각이나 진행률을 추정하지 않는다.
- 급식은 표시 날짜의 메뉴가 있는 식사만 순서대로 보여준다. 넓은 카드의 열 수는 실제 식사 수를 따르며, 긴 메뉴는 각각 스크롤한다. 세 종류를 넘는 자료는 세로 목록으로 보존한다. 빈 조식·다른 날짜 제외와 마지막 메뉴까지의 접근을 검사했다.
- 설정 > 위젯에서 앱 색상, 라벤더·로즈·민트·피치·블루를 선택한다. 밝기·교사명 설정을 공유하고 앱 색상 모드는 배경화면 기반 Material 색상을 사용한다. 색상 설정 변경·배경화면 색상 변경 시 다시 그리며, 밝은/어두운 기본 본문 색상 대비를 검사했다. 배경 비트맵 크기를 제한한다.
- 앱·알림의 조회와 캐시 삭제 시 위젯도 갱신한다. 위젯이 있을 때만 15분 주기 백그라운드 작업을 등록하고, 시스템 30분 갱신·다음 시작 시각·날짜 변경·재부팅·앱 업데이트·수동 ↻ 갱신을 함께 처리한다. 실제 실행 시점은 OS 절전 정책을 따른다. 위젯을 모두 지우면 관련 작업과 시각 예약을 취소한다.
- JVM 테스트 총 33개 통과. 위젯 모델 테스트 4개는 실제 메뉴·당일 필터, 제공된 시작 시각 기반 요약, 취소/시각 누락, 크기·큰 글꼴 배치 전환을 검사한다.
- Android 17 에뮬레이터 계측 검사 4개 통과: `WidgetHostTest`, `WidgetSettingsTest`, `NotificationUiTest`, `MealUiTest`. 실제 AppWidgetHost 바인딩, 네 가지 레이아웃, 긴 메뉴 스크롤, 7교시 표시, 크기 변경, 색상·다크 모드, 연결 해제, 팔레트 저장·재생성, 위젯 탭 이동과 기존 알림·급식을 확인했다.

## 매일 시간표·급식 알림 — 2026-10-28 KST

- 기준: 앞선 초기 설정·급식 카드 정리가 포함된 워크스페이스. 버전 `0.2.1-beta` / versionCode `4`를 유지하는 로컬 디버그 빌드다.
- 초기 설정은 학교·학급 → 급식 학교 → 알림의 3단계다. 시간표·급식의 사용 여부와 시각을 각각 저장하며 기본값은 꺼짐, 시각은 각각 07:30·11:30이다. 기존 사용자는 설정 탭의 알림 영역을 사용하며 초기 설정을 다시 강제하지 않는다.
- 한국 시간 기준으로 다음 예약 시각을 계산하고 AlarmManager의 일회성 알람을 매일 다시 등록한다. 알림 권한·채널 상태를 확인하며, 정확한 알람 접근이 없으면 지연 가능한 예약을 사용하고 UI에서 안내한다. 재부팅·앱 업데이트·기기 시각 변경·정확한 알람 허용 및 앱 복귀 시 다시 예약한다.
- 알람 수신기는 WorkManager에 자료 조회·발송을 넘긴다. 같은 시각으로 지정해도 시간표·급식을 별도 작업과 채널·알림 ID로 발송한다. 날짜·현재 학교·시각·스위치를 재검증하고 날짜별 발송 기록으로 중복을 막는다. 끄거나 학교 연결을 해제하면 해당 예약·진행 작업·기존 알림을 취소한다.
- 펼친 시간표 알림은 오늘의 실제 수업만 교시순으로, 급식 알림은 오늘 메뉴가 있는 식사만 순서대로 표시한다. 네트워크 오류 시 해당 주·날짜 캐시에 한해 마지막 조회 시각을 덧붙인다. 저장된 자료도 없으면 조회 실패를 안내한다. 알림을 누르면 오늘·급식 탭으로 이동한다.
- JVM 테스트 총 29개 통과. 알림 모델 테스트 5개는 한국 시각·정각·자정·연말 경계, 독립 설정과 초기 설정/학교 전제조건, 수업 필터·정렬·교사명 설정, 식사 순서·빈 메뉴/다른 날짜 제외를 확인한다.
- Android 17 에뮬레이터의 격리된 `.smoke` 앱에서 계측 테스트 4개 통과: `NotificationUiTest`, `InitialSetupTest`, `EmulatorSmokeTest`, `MealUiTest`.

- 일반 디버그 APK 빌드·Lint 통과(오류 0, 기존 의존성 안내 경고 6). 내장 NEIS 키가 로컬 `neis.properties`와 일치하는지 APK에서 확인했다. 키 값은 기록하지 않는다.
