# 컴시간neo 0.1.0 베타

Kotlin·Jetpack Compose Material 3 기반 컴시간알리미 비공식 Android 클라이언트의 첫 베타입니다.

## 주요 기능

- 학교 검색 및 학년·반 선택
- 오늘 수업, 이번 주·다음 주 시간표, 변경 수업 상세
- 월~금이 함께 보이는 주간표와 일별 목록
- Material You 동적 색상, 다크 모드, 교사명 표시 설정
- 오프라인 캐시와 수동 새로고침

## 설치

- Android 8.0(API 26) 이상에서 지원합니다.
- 배포용 키로 서명한 release APK를 제공합니다. APK와 함께 제공하는 SHA256SUMS.txt로 파일 무결성을 확인할 수 있습니다.
- 이전 디버그 APK와는 서명 키가 다릅니다. 디버그 버전이 설치된 기기에는 앱을 제거한 후 베타를 설치해야 하며, 기기에 저장한 설정과 캐시는 제거됩니다.
- 이후 같은 배포 키로 서명한 버전으로 업데이트할 수 있습니다.

## 검증

- JVM 파서·모델 회귀 테스트 10개
- Android 17 에뮬레이터의 학교 선택·주간 전환·테마·Activity 재생성 시나리오
- 오프라인 프로세스 재시작과 새로고침 실패 시 캐시 유지
- Android Studio 서명 APK 생성 및 apksigner 서명 검증

에뮬레이터 실행 검증은 디버그 빌드에서 수행했습니다. 이번 서명 release APK는 빌드·서명·버전 메타데이터를 검증했으며 기기 설치 검증은 남아 있습니다.

배포 서명 인증서 SHA-256: `4ec949d20e32a7b037d4c41071d162a6a014455d277a83aabaf6a274abf4e8ba`

## 베타의 제약

알림, 위젯, 여러 학급 즐겨찾기, 교사용 시간표는 아직 지원하지 않습니다.
실물 기기와 Android 8~16의 검증은 남아 있습니다. 서버 구조나 학교 게시 상태에 따라 조회가 제한될 수 있습니다.
컴시간 및 운영 주체와 공식적인 관계가 없는 오픈소스 프로젝트입니다.
