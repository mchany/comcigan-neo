# enc5 요청 형식 대응 및 검증

확인일: 2026-11-07. 기준 main: `810c48744626ad1bf9962dbb3f60cfff0e2a4ab4`.

## 원인과 변경 사항

기존 enc2 대응 이후 공식 페이지의 요청·키 표현이 다시 바뀌었다. 바깥 `hour-obfuscated-v2` 안에 `hour-ajax-obfuscated-v1` 블록이 추가됐고, `QAjaxSchool`과 `QAjaxTimetable`의 요청을 읽어야 한다.

- 알려진 두 마커의 중첩 문자열을 최대 4단계 복원한다. JavaScript는 실행하지 않는다. 페이지 해석을 `ComciganServicePage`로 분리했다.
- 검색어를 JavaScript `encodeURIComponent`와 같은 UTF-8 표현으로 변환하고, 검색 요청 접두사와 `_enc5`를 붙인 문자열 전체를 Base64로 변환한다. 최종 Base64 값도 URI 인코딩한다. 공백은 `+` 대신 `%20`으로 처리한다.
- 시간표는 기존 토큰의 접미사를 `_enc5`로 처리한다. 경로·검색 접두사·시간표 요청 코드·자료 필드 번호는 현재 페이지에서 읽는다.
- 응답 키는 평문 Hex 리터럴 또는 제한된 배열 인덱스 연결식에서 읽는다. 키 조각과 연결 순서를 해석하며, 운영 키나 순서 값을 코드에 고정하지 않는다. 지원하지 않는 표현은 오류로 거부한다.
- `enc5:` Base64 응답을 추가로 지원한다. HMAC 검증 시 원본 접두사를 유지하며, 인증 성공 후 AES-CBC/PKCS7 복호화를 수행한다. 접두사를 enc2로 바꾸면 인증값이 달라지므로 단순 치환하지 않는다.
- 기존 enc1/enc2 응답, 기존 MS949 검색 및 가변 학교 코드 열 처리는 유지한다.
- 버전: `1.0.3` / versionCode `13`. `-dontobfuscate`, 코드 최적화 및 리소스 축소 설정을 유지한다.

## 자동 및 실제 서버 검증

- JVM 테스트 총 45개 통과. 두 AJAX 블록의 중첩 복원, 동적으로 달라지는 키 순서, 한글·공백·특수문자 및 Base64 패딩의 요청 인코딩을 검증했다.
- .NET으로 독립 생성한 합성 enc5 암호문으로 학교 코드 열 선택과 시간표 파싱을 확인했다. 접두사·암호문 변조, 잘못된 키 표현·인덱스·경로, 지원하지 않는 스크립트 및 과도한 중첩을 거부하는지 확인했다.
- 실제 Kotlin 클라이언트로 중일고등학교 검색과 1학년 1반 시간표 조회 성공: 2026-11-02 주간 수업 29개, 2026-11-09 주간 수업 34개.
- Release APK 빌드와 Release Lint 통과.
- 기존 배포 인증서 일치, 비디버그 설정, 16KB APK 정렬, 최종 DEX의 내장 나이스 키, 개인 빌드 입력 파일 제외 확인. 비밀번호와 내장 키 값은 로그에 출력하지 않았다.
